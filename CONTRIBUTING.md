# Contributing

Cube is currently seeking **design review and falsification** rather than production usage.

Please start with an Issue describing a concrete use case, existing alternative, security/privacy concern, or reproducible failure.

Avoid real user data, tokens, credentials or untrusted third-party code. APIs are experimental. There is currently **no open-source license**; code contributions should be discussed before submission, and publication does not grant general reuse rights.

Read [review questions](docs/REVIEW_REQUEST.md) and [experiment plan](docs/EXPERIMENT_PLAN.md).
