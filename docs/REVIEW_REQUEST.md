# Human design review — critical feedback wanted

Cube is an early research effort, not a secure or deployable SDK. We need concrete disagreement, not endorsements.

1. What integration problem involving independently maintained apps/plugins have you actually encountered?
2. How would you solve it with existing tools (CloudEvents, OAuth/OIDC, OpenFGA, plugin APIs, NATS, etc.)?
3. Does a shared contract add enough value to justify its new complexity?
4. What is the smallest realistic third-party module worth demonstrating?
5. What authorization, revocation, or privacy failure is most likely?
6. How can separate pseudonymous identities be preserved across applications?
7. What comparison would most convincingly disprove Cube's hypothesis?

Please open an Issue with examples, links and explicit counterarguments. No personal data or secrets.
